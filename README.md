iOS Container Diagnostics

An iPhone-focused diagnostic utility for exploring files and capabilities available to an app under Apple’s iOS security model.

Planned features

* Show the app’s sandbox and accessible directories.
* List files and folders the app is permitted to read.
* Report basic app and operating-system information.
* Explain which access restrictions are enforced by iOS.

Important limitation

This tool does not bypass iOS sandbox protections or automatically access another app’s private container, including PUBG Mobile’s data.

Build status

Prototype planning stage. No signed iOS app has been built yet.
